# Sales Learning Plan

A capability-based development program for technical founders and consultants transitioning from **building** expertise to **selling** expertise — qualification, discovery, positioning, and pipeline discipline.

Designed to be adapted. Built in the same format as [tl-learning-plan](https://github.com/cristoslc/tl-learning-plan).

## What's in here

All curriculum content lives in `docs/`.

- **Capability map** (`docs/_0 concept-map.md`) — 10 capabilities that change how you show up in sales conversations, plus an AI-as-leverage thread. Start here.
- **Capability deep-dives** (`docs/capability-*.md`) — one page per capability with situation, what changes, readiness check, curated resources, and a practice exercise.
- **Interactive capability map** (`docs/capability-map.html`) — filters and progress tracking.

## How to use this

1. Read the capability map to see the full landscape.
2. Pick the capability that matches your most pressing gap, or start with Capability 1 and work in order.
3. Use practice, not tests. Each capability has a concrete exercise designed to produce a real artifact for your next real deal. A capability is "done" when you've run it live, not when you've read the material.

## Design principles

- **Capability-based, not topic-based.** Each capability describes a situation, what changes after learning it, and a self-check — not a list of topics to cover.
- **Practice-driven assessment.** The only signal that matters is what happens on real calls and in real proposals. There are no quizzes.
- **Curated, not comprehensive.** Each capability has a "Start Here" (one or two resources) and a "Go Deeper" section. Get the idea across fast, don't assign a reading list.
- **AI-assisted learning.** Use AI for role-play, deal review, and first-draft outreach — then run it live with a prospect. The reps are the point.
